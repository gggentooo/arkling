# Arkling
Tool for learning either Mandarin/English/Japanese/Korean in either Mandarin/English/Japanese/Korean, with help from the extremely educational and totally-appropriate-for-language-learning-resource, the Arknights game script

Vibeslopped (with love) by @gggentooo
(Overly grotesquely sloppy parts are manually edited by myself)

---
## Features
### Complete
- Two learning modes (side-by-side / focused)
- Automatic pinyin/furigana/romaji annotations

### Not yet implemented
- Sentence parser & automatic vocabulary list generation
- Exportable custom vocabulary list & notes (saved & loaded locally)

---
## External libraries used
- pinyin-pro: Mandarin pinyin annotation
- kuroshiro, kuroshiro-analyzer-kuromoji: Japanese furigana / romaji annotation
